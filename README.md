Entry for the make.fun bounty **The Funniest Out-of-Office**:
https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf

`main.ts` writes a single out-of-office auto-reply line (140 characters or
fewer) to `/output/entry.txt`. The line: the auto-reply itself is also out
of office, so the message you're reading is the under-qualified temp
covering for it — and it's already behind.

Run it with Node 22:

```sh
node main.ts
```
